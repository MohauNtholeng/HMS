# HMS

Employee Health Management System.

## Features

- Supports multiple clinics within the same system.
- Employees can book appointments directly.
- HR staff can book appointments for employees.
- Supported appointment types:
  - `pr-employment`
  - `annual check up`
  - `exit appointment`
  - `walk in`
  - `emmergencies`

## Run tests

```bash
python -m unittest discover -s tests -v
```
